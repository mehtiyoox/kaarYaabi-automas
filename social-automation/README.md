# سیستم اتوماسیون تولید محتوا برای توییتر/X و لینکدین (مهدی حبیب‌زاده)
این سیستم برای شما ساخته شده تا به صورت خودکار محتوای حرفه‌ای برای جذب مشتری فریلنس در شبکه‌های اجتماعی تولید و زمان‌بندی کند.
با استفاده از این سیستم شما بدون صرف ساعت‌ها وقت در روز، فعالیت منظم و هدفمند در توییتر و لینکدین خواهید داشت و به سرعت به درآمد ۵۰۰ دلار در ماه می‌رسید.

## 🎯 هدف اصلی سیستم
1.  **ساخت پرسونال برند شما به عنوان AI Automation & Workflow Developer**
2.  جذب لید و مشتری فریلنس مستقیم (بدون نیاز به پلتفرم‌های واسطه)
3.  نمایش نمونه کارها و نتیجه پروژه‌های شما
4.  درآمدزایی: رسیدن به حداقل ۲ درخواست پروژه در هفته در ماه اول

## 📁 ساختار پروژه
```
social-automation/
├── content/            # تمام پست‌های آماده اولیه ۲ هفته + تقویم محتوایی ۳۰ روزه
├── scripts/            # اسکریپت پایتون برای تولید خودکار پست با LLM
├── n8n-workflows/      # ورکفلوهای آماده n8n برای انتشار خودکار در شبکه‌ها
├── docs/               # راهنمای کامل راه‌اندازی سیستم در کمتر از ۳۰ دقیقه
└── assets/             # تصاویر و الگوهای ویدیو برای پست‌ها
```

## 🚀 شروع سریع
**نسخه تولید حرفه‌ای سیستم آماده شد!** این نسخه مطابق با استراتژی و سطح محتوای برترین سازندگان حوزه اتوماسیون و n8n در دنیا طراحی شده و نرخ دریافت لید آن به مراتب بالاتر است.
1.  **همین امروز شروع کنید:** فایل `content/01-first-two-weeks-HIGH-CONVERTING-posts.md` را باز کنید — این پست‌ها با الگوهای امتحان پس‌دهی که میلیون‌ها بازدید گرفته‌اند نوشته شده‌اند، هر روز یکی را کپی و منتشر کنید.
2.  **استراتژی به روز را حتما بخوانید:** فایل `content/00-UPDATED-high-converting-content-strategy.md` الگوهای پست‌های پرلید را کامل توضیح می‌دهد.
3.  **برای راه‌اندازی سیستم کاملا خودکار تولید گرید:** به پوشه `n8n-workflows/production/` بروید، فایل `SETUP_GUIDE_PRODUCTION.md` را دنبال کنید.
⚠️ توجه: محتوای داخل پوشه `docs/` و پست‌های قدیمی نسخه ساده سیستم هستند، برای نتیجه حرفه‌ای از محتوای جدید استفاده کنید.
