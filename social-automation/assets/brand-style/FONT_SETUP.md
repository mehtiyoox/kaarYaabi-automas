# Font Setup Instructions
The image generator uses Inter Bold and Inter Regular fonts for all branded post images.

If the automatic font download did not work:
1.  Download Inter font from https://rsms.me/inter/
2.  Place these two files in this folder:
    - `Inter-Bold.ttf` (or .otf)
    - `Inter-Regular.ttf` (or .otf)

The script will automatically detect and use them. If Inter is not available the script will fall back to system default fonts, but for consistent brand appearance Inter is strongly recommended.
