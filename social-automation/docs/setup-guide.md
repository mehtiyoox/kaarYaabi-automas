# راهنمای کامل راه‌اندازی سیستم اتوماسیون شبکه‌های اجتماعی
شما می‌توانید این کل سیستم را در کمتر از ۳۰ دقیقه کامل راه‌اندازی کنید.

## 📋 مراحل پیش‌نیاز
اول این موارد را آماده کنید:
1.  یک کلید API از سایت [console.groq.com](https://console.groq.com) بسازید (رایگان است، برای تولید محتوا با LLM کافی است)
2.  اکانت نرون دیتابیس رایگان از [neon.tech](https://neon.tech) برای ذخیره پست‌های زمان‌بندی شده
3.  دسترسی توسعه‌دهنده اکانت لینکدین و توییتر/X (در زیر توضیح داده شده)
4.  n8n را می‌توانید روی همان سروری که الان ربات‌های خودتان را می‌چرخانید، با داکر اجرا کنید.

---

## مرحله ۱: آماده‌سازی اسکریپت تولید محتوا
1.  ابتدا پکیج‌های مورد نیاز را نصب کنید:
    ```bash
    cd scripts
    pip install -r requirements.txt
    ```
2.  یک فایل `.env` در پوشه اسکریپت بسازید و کلید API گروک را در آن قرار دهید:
    ```env
    GROQ_API_KEY=your_groq_api_key_here
    ```
3.  حالا می‌توانید در هر لحظه پست جدید برای هر موضوعی که می‌خواهید تولید کنید:
    ```bash
    # مثلا پست نتیجه پروژه در مورد ربات جمع‌آوری لید
    python content_generator.py --topic "ساخت ربات جمع‌آوری لید از گروه‌های تلگرام" --type project_result

    # مثلا پست آموزشی در مورد اتوماسیون بکاپ خودکار
    python content_generator.py --topic "بکاپ خودکار وردپرس با n8n" --type tip

    # مثلا پست داستان شخصی
    python content_generator.py --topic "تجربه من از اولین پروژه فریلنس بین‌المللی" --type personal_story

    # مثلا پست فراخوان برای قبول پروژه
    python content_generator.py --topic "پذیرش ۲ پروژه اتوماسیون جدید در این هفته" --type cta
    ```
4.  پست تولید شده به طور خودکار در پوشه `content/generated/` ذخیره می‌شود، بعد از اینکه یک بار خواندید و تایید کردید، می‌توانید آن را در دیتابیس پست‌های زمان‌بندی شده وارد کنید.

---

## مرحله ۲: آماده‌سازی دیتابیس
در نئون/پستگرس این جدول را بسازید:
```sql
CREATE TABLE scheduled_posts (
  id SERIAL PRIMARY KEY,
  topic TEXT NOT NULL,
  content_linkedin TEXT NOT NULL,
  content_twitter TEXT NOT NULL,
  image_url TEXT,
  scheduled_for TIMESTAMP WITH TIME ZONE NOT NULL,
  published BOOLEAN DEFAULT false,
  published_at TIMESTAMP WITH TIME ZONE,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

حالا پست‌هایی که تولید و تایید می‌کنید را در این جدول وارد کنید، مثلا:
```sql
INSERT INTO scheduled_posts (topic, content_linkedin, content_twitter, scheduled_for)
VALUES (
  'دستیار فروش هوشمند',
  'متن لینکدین اینجا...',
  'متن توییتر اینجا...',
  '2026-10-13 11:30:00+03:30'
);
```

## مرحله ۳: راه‌اندازی ورکفلو n8n انتشار خودکار
1.  در n8n خودتان، ورکفلو فایل `n8n-workflows/social-media-publisher.json` را ایمپورت کنید.
2.  این اعتبارنامه‌ها را در ورکفلو تنظیم کنید:
    - اتصال به دیتابیس نئون/پستگرس
    - اکانت لینکدین (از اتصال داخلی n8n استفاده کنید)
    - اکانت توییتر/X (از اتصال داخلی n8n استفاده کنید)
    - اکانت ربات تلگرام خودتان برای ارسال اعلان انتشار
3.  آیدی چت تلگرام شخصی خودتان را در گره `Send Notification to Me` جایگزین کنید.
4.  ورکفلو را فعال کنید.

#### نحوه کارکرد ورکفلو:
- دو بار در روز، در ساعات ۱۱:۳۰ و ۱۷:۳۰ به وقت ایران اجرا می‌شود.
- اولین پست تایید نشده‌ای که زمان انتشارش رسیده است را از دیتابیس می‌گیرد.
- به طور همزمان در لینکدین و توییتر منتشر می‌کند.
- پست را به عنوان منتشر شده علامت می‌زند.
- برای شما در تلگرام اعلان می‌فرستد که پست با موفقیت منتشر شد.

---

## مرحله ۴: تنظیمات اضافی اختیاری
اگر می‌خواهید سیستم کامل‌تر شود، می‌توانید این گره‌ها را هم به ورکفلو اضافه کنید:
1.  **پاسخ خودکار به کامنت‌ها:** هر ۱ ساعت یکبار کامنت‌های جدید پست‌ها را بخوانید، با LLM پاسخ مناسب تولید کنید و در صورت سوال ساده پاسخ دهید، در صورت سوال در مورد پروژه فورا برای شما اعلان بفرستد.
2.  **پیشنهاد خودکار ایده پست:** هر یکشنبه شب با LLM ۱۰ ایده پست جدید برای هفته بعد تولید کند و برای شما در تلگرام بفرستد تا تایید کنید.
3.  **آمار بازدید و تعامل:** هر هفته گزارش آمار پست‌ها را برای شما بفرستد تا ببینید کدام پست‌ها بهتر عمل کرده‌اند.

---

## ⚠️ نکات مهم
1.  **همه پست‌ها را قبل از زمان‌بندی یک بار با چشم خودتان بخوانید!** هوش مصنوعی گاهی اشتباه می‌کند، هیچ وقت بدون خواندن پست را برای انتشار زمان‌بندی نکنید.
2.  در شروع کار، ۳۰ دقیقه در روز وقت بگذارید و به کامنت‌های پست‌ها پاسخ دهید، این مهم‌ترین بخش کار برای جذب مشتری است.
3.  نرخ پاسخ به کامنت‌ها در همان اول روز، به شدت به الگوریتم شبکه‌ها می‌گوید که پست شما را به افراد بیشتر نمایش دهد.
4.  بعد از اینکه چند مشتری از طریق این پست‌ها به دست آوردید، نتیجه را خودش به عنوان یک پست جدید منتشر کنید، این محتوا بهترین اثبات کار شما خواهد بود.
