## مرحله ۱: نصب داکر و n8n روی سرور
اگر از قبل n8n را با داکر نصب دارید این مرحله را رد کنید، در غیر این صورت دقیقا این دستورات را در ترمینال سرور اجرا کنید:
```bash
# به روز رسانی سیستم
sudo apt update && sudo apt upgrade -y

# نصب داکر
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
sudo usermod -aG docker $USER
newgrp docker

# ساخت پوشه برای دیتای n8n
mkdir -p ~/n8n-data
```

حالا سرویس n8n را با داکر کامپوز اجرا کنید. یک فایل به نام `docker-compose.yml` در پوشه `~/n8n-data` با محتوای زیر بسازید:
```yaml
version: '3.8'

volumes:
  n8n_data:

services:
  n8n:
    image: docker.n8n.io/n8nio/n8n:latest
    restart: always
    ports:
      - "5678:5678"
    environment:
      - TZ=Asia/Tehran
      - GENERIC_TIMEZONE=Asia/Tehran
      - N8N_HOST=آدرس-ایپی-یا-دامنه-سرور-شما
      - N8N_PROTOCOL=http
      - WEBHOOK_URL=http://آدرس-ایپی-یا-دامنه-سرور-شما:5678/
    volumes:
      - n8n_data:/home/node/.n8n
```

بعد از ذخیره فایل، n8n را اجرا کنید:
```bash
docker compose up -d
```
حالا اگر در مرورگر آدرس `http://آدرس-سرور-شما:5678` را باز کنید، صفحه خوش‌آمدگویی n8n نمایش داده می‌شود. اولین اکانت ادمین را بسازید.

## مرحله ۴: ساخت کلیدهای API مورد نیاز
### API کلید برای تولید محتوا:
به https://console.groq.com بروید و یک API Key رایگان بسازید. برای شروع این سرویس کاملا رایگان و بسیار سریع است، اگر بعدا به کیفیت بالاتر نیاز داشتید می‌توانید از GPT-4o استفاده کنید. این کلید را در جای امن نگه دارید.

### API کلید توییتر/X:
1.  وارد https://developer.twitter.com شوید و با اکانت خود وارد شوید.
2.  یک پروژه جدید به نام `Mehdi Social Automation` بسازید.
3.  در تنظیمات پروژه، دسترسی برنامه را روی `Read and Write` تنظیم کنید.
4.  در بخش Callback URL این آدرس را وارد کنید:
    `http://آدرس-سرور-شما:5678/rest/oauth2-credential/callback`
5.  کلیدهای API Key، API Secret، Access Token و Access Token Secret را کپی کنید.
6.  در n8n یک اعتبارنامه جدید از نوع X/Twitter API OAuth2 بسازید و کلیدها را در آن وارد کنید.

### اتصال اکانت لینکدین:
1.  در n8n یک اعتبارنامه جدید از نوع LinkedIn OAuth2 بسازید.
2.  روی دکمه `Connect my account` کلیک کنید، با اکانت لینکدین وارد شوید و دسترسی‌ها را تایید کنید. بسیار ساده است و نیاز به کلید اضافی ندارد.
3.  حتما این دسترسی‌ها را برای اپ فعال کنید:
    - `w_member_social` (انتشار پست)
    - `r_liteprofile`
    - `r_comments`
    - `w_comments`

### ساخت ربات تلگرام برای کنترل سیستم:
1.  در تلگرام به @BotFather بروید و با دستور `/newbot` یک ربات جدید بسازید.
2.  توکن ربات را کپی کنید.
3.  آیدی عددی اکانت شخصی خودتان در تلگرام را با ارسال پیام به @userinfobot به دست بیاورید.
4.  در n8n یک اعتبارنامه جدید از نوع Telegram Bot API بسازید و توکن ربات را در آن وارد کنید.
